## 1. 플로팅이란
플로팅 상태란 PIN(판)이 VCC, GND에 연결되어있지 않고 떠 있는 상태이다. MCU는 핀에 걸린 전압을 읽어서 0V일 떄 값을 0가지고, 5V일 떄 값을 1 가지는데, 이 어느 상태도 읽지 못하니 스위치의 치명적인 약점이다.

## 2. 왜 문제일까
입력값이 불확정 해진다. MCU 입력 핀은 임피던스가 매우 높아서, 아주 작은 전류만으로도 전압이 흔들인다. 주변 배선의 노이즈, 정전기, 손을 가까이 대는 것만으로도 0과1이 멋대로 바뀐다. 또한 읽을 떄마다 값이 달라지는데 스위치를 안 눌렀는데 눌린 것처럼 인식되거나, 그 반대가 된다. 인터럽트로 쓸 경우 아무도 안 눌렀는데 ISR이 마구 호출되는 현상이 생길수도 있다.

## 3. 해결방법은?
1. 풀업저항<br>
   핀과 VCC 사이에 저항을 연결한다.그러면 스위치off 일 때 저항을 통해 VCC에 연결되고 5V 논리1이 된다.

   즉  누르면 0 때면 1인 상태가 되고 저항이 있기 때문에 스위치를 눌러도 단락이 되지 않는다.

2. 풀다운 저항<br>
   핀과 GND사이에 저항을 연결한다. 풀업과 반대로 누르면 1 때면 0 논리구조가 된다.

3. 내부 풀업<br>
   아트메가128은 각 핀에 내부 풀업 저항이 내장되어 있다.
