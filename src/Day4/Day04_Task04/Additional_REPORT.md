# 필터링 보고서

## 사용된 필터의 개념(이동 평균 필터)

### 8개의 값의 평균

근접한 8개의 값들을 배열에 저장한 뒤에 그 값들의 평균을 낸다. 또한 그 이후에 새로운 값들로 평균을 내어 새로운 값을 보출하는 방식을 반복한다.<br>

(아래는 코드에서 실제 사용된 예제 설명) 

* int movingAvg(int adc)<br>
{<br>
	static int buf[8]; <br>
	static int idx, sum, cnt; <br>
	sum -= buf[idx];	//버릴 값을 합계에서 뺀다<br>
	buf[idx] = adc;		//그 자리에 새 값을 넣는다<br>
	sum += adc;		//새 값을 더한다<br>
	...<br>
	return sum / cnt;<br>
}<br>

## 특징
* 매번 8개를 다 더하지 않고 빼고 더하기 두 번으로 끝냄
* 구현이 단순하고 계산이 가벼움
* N값이 커질수록 반응이 느려짐

## 필터 값의 변화
Raw 값은 좀 더 많은 상승 하락폭을 보였다면 필터링된 값은 낮은 폭의 변화를 보임.
